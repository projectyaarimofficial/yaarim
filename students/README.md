# תלמידים (Students)

כל תלמיד = תיקייה עם המבנה הבא:

```
<student_id>/
  profile.json      ← מי הוא (קבוע)
  status.json       ← מצב נוכחי — לבנות חסרות (open/closed)
  sessions/         ← זיכרון: סיכומי שיחות, קובץ ליום (YYYY-MM-DD.json)
  quiz_results/     ← מדידה: תוצאות מבחנים, קובץ ליום (YYYY-MM-DD.json)
```

## דמו מול אמיתי

התלמידים מופרדים לשתי תיקיות כדי שתמיד יהיה ברור מה אמיתי ומה לא:

- `demo/` — תלמידים לבדיקות/הדגמה (כמו `eitan`). לא נתונים אמיתיים.
- `real/` — תלמידים אמיתיים. נתונים רגישים — לא לשתף.

בנוסף, כל `profile.json` מסומן ב-`"is_demo": true/false`, כך שגם אם קובץ זז
ממקומו עדיין ברור אם מדובר בנתוני דמו או אמיתיים.
